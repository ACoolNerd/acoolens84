## Setup
Ensure you have [Node.js](https://nodejs.org) installed.

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the local development server:**
   ```bash
   npm run dev
   ```

3. **Access the platform:**
   Open [http://localhost:3030](http://localhost:3030) in your browser.
